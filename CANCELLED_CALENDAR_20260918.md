# Календарь отменённых — Android 0.1.51 (52)

Первый этап: просмотр истории, без перезаписи.

- Подсвеченная кнопка перечёркнутого календаря рядом с обновлением и подпись режима.
- Обычные заказы скрыты только на экране. Отменённые — на прежних местах,
  с красноватым фоном и перечёркнутым именем.
- Периоды отмены: все, сегодня, текущая неделя с понедельника.
- «Даты с отменами» показывает даты визитов и количество отмен для всего
  персонала с учётом периода. Можно перейти к следующему месяцу.
- Список в видимых днях позволяет открыть пересекающиеся карточки,
  учитывает выбранных сотрудников. В режиме сотрудников показывается один день.
- Карточка: клиент, услуги, сотрудник, прежний интервал, источник записи,
  время отмены, примечания. Причина/инициатор отмены не выдаются за известные.
- Нет действий перетаскивания, оплаты, смены статуса или создания записи
  в режиме отмен. Перезапись пока не реализована.
- Исправлено переполнение календаря на маленьком экране.

API: GET /api/v1/calendar/day/?date=YYYY-MM-DD&cancelled=all|today|week.
Без cancelled поведение прежнее. Режим разрешён owner/admin/employee,
существующий скоуп доступа не расширялся. cancellation_dates служит для навигации.

Миграция bookings.0023_booking_cancelled_at добавляет точную дату отмены.
Booking.save() фиксирует новые переходы; Bulk SQL update обходит save().
Старые отмены остаются с NULL: используется updated_at с явной пометкой
приблизительной даты. Исторические причины отмен не исследовались.

Проверено: 110 тестов Django и 8 Flutter, повторная проверка новых фильтров
и перехода к следующему месяцу. UI проверен на экране 390×844. Анализ Dart
без ошибок/предупреждений, имеются стилистические info о const.
API на сервере проверен read-only на существующей записи.
